Get started

Connect your AI chat to the Internet Computer

Point Claude, ChatGPT, or any MCP-capable app at this server and work with the IC in plain language, no code required. You sign in with your Internet Identity, and the agent acts as you, with only the access you grant.

Connector URL https://mcp.beta.id.ai/mcp-prod

  1. Sign in and trust this server

    Open id.ai/manage/settings, sign in to the identity you want the agent to act as, and add the connector URL above under Trusted MCP servers.

  2. Add the same URL to your AI app

    Paste the connector URL as a custom connector or MCP server. Where to find it:

    Claude (Desktop or claude.ai)
    Settings → Connectors → Add custom connector, then paste the URL. Set Read-only tools to Always allow so lookups run smoothly, but leave Write/delete tools on Ask so the agent checks with you before any state-changing action.
    ChatGPT (chatgpt.com)
    Settings → Apps (called Connectors or Plugins on some plans). Enable Developer mode under Advanced settings first (despite the name, no coding is involved), then press Create app and paste the URL.
    Any other app
    Look for MCP, connectors, or plugins in the app's settings, then add the URL as a new server.

  3. Authorize, then talk

    Your app sends you to Internet Identity to grant access. Pick the identity and how long the grant lasts, then choose Actions & questions if you want the agent to act (call methods, create and manage canisters), or Questions-only mode to have it look things up without changing anything. Grants expire by design, so re-approving later is normal, not a fresh setup.

    Then try: "What canisters run multidex.ai?" · "Look up the ckUSDC ledger" · "What's my cycles balance?" · "Show my accounts at the NNS"

    Revoke access at any time in your settings.

§ 01 Service discovery

Find canisters and learn what they are

Turn a domain, a name, or a bare id into something you can call.

discover_app_canisters

Map a domain or app URL to the canister ids it runs on.

icp_find_canister_by_name

Look up canister ids by a well-known name (e.g. ckUSDC, ICP Ledger).

icp_find_app_by_name

Resolve a well-known app name to its URL and Internet Identity derivation origin.

icp_lookup_canister_info_by_id

Identify a bare canister id: label, type, controllers, subnet, and module hash.

get_canister_candid

Read a canister's Candid (.did) interface from its public metadata.

get_canister_api_doc

Read a canister's own "how this app behaves" guide, when it publishes one.

§ 02 User identity

Act as your Internet Identity at an app

Delegations are minted on demand. Results echo the origin they were derived for, so a mismatch is always visible.

list_app_accounts

List your Internet Identity accounts at a given app.

get_app_principal

Get your principal at an app, without making a call.

resolve_app

Resolve an app URL to its Internet Identity derivation origin.

§ 03 OQL

Query canisters that expose an OQL surface

For canisters where get_canister_candid reports oql: true.

icp_oql_guide

Load the OQL query dialect guide. Read this first so queries are correct.

get_canister_oql_schema

Inspect a canister's OQL entities, fields, and edges.

run_canister_oql_query

Run a JSON OQL query and get a table back.

§ 04 Actions

Call methods and manage canisters

Anonymously, or as your Internet Identity. Management calls need an authenticated session.

call_canister

Call any canister method, anonymously or as your account at an app.

icp_cycles_balance

Check your cycles-ledger balance, the cycles that create and top-up spend.

icp_create_canister

Create a new canister, funded from your cycles balance.

icp_top_up_canister

Add cycles to a canister.

icp_install_code

Install, reinstall, or upgrade a canister's Wasm module.

icp_canister_status

Report a canister's run state, cycles, memory, and controllers.

icp_update_canister_settings

Change controllers, allocations, thresholds, or log visibility.

icp_start_canister

Start a stopped canister you control.

icp_stop_canister

Stop a running canister, required before deleting it.

icp_uninstall_code

Remove a canister's code and state, keeping its id and cycles.

icp_delete_canister

Delete a canister permanently. Stop it first; remaining cycles are burned.

§ 05 Skills

Official Internet Computer how-to guides

Authoritative guides for building and shipping IC apps. Consult these before writing canister code or deploying.

icp_list_skills

List the official IC skills: Motoko, mops, the icp CLI, cycles, security, and more.

icp_get_skill

Fetch one skill's full instructions by name.

Every tool speaks textual Candid. The server handles all encoding and decoding, so an agent only ever reads and writes Candid text. Identity results include derived_for_origin and requested so an origin mismatch stays visible.
